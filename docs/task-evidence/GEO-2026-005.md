## Scope Implemented

- Added Goose migration `20260907000009_zone_versioning_lifecycle.sql` to widen `zones.polygon` to PostGIS Polygon/MultiPolygon geometry, add `market_code` and `geometry_version`, create indexed `zone_revisions`, and backfill a published baseline for existing zones.
- Preserved materialized-view definitions and indexes while changing the PostGIS column type; the migration has a working DOWN path.
- Routing resolves only active zones in the configured `MARKET_CODE` and uses `ST_Covers`, which includes points on polygon boundaries.
- Existing zone/courier/service lookups continue to use the canonical `zones` and `courier_zones` ownership model, so provider/capability availability can remain zone-referenced without a duplicate registry.
- Admin zone updates create versioned drafts. The admin GUI exposes revision preview/diff, maker-checker approval, TOTP-protected publish, published-revision rollback, and explicit deactivation.
- Zone publish/rollback/deactivation update zone configuration only; no order leg is nulled or reassigned. Preview reports the active order assignment count that remains preserved.
- Boundary-provider MultiPolygon results are emitted as `MULTIPOLYGON` WKT rather than silently reducing the geometry to the largest polygon.
