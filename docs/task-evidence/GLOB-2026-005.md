## Scope Implemented

- Extended the existing `event_outbox` with canonical schema/timestamps, market/service/actor/entity/correlation/trace identity, event/field PII classification, retention class, and deterministic dedupe metadata.
- Added compatibility-preserving canonical envelope construction in admin-service and canonical wire publication to RabbitMQ. Sensitive headers are allow-listed; raw idempotency and actor headers are not forwarded.
- Added datalake-worker envelope/domain validation, registered schema versions, dead-letter routing for invalid messages, durable append-only JSONL landing, and redelivery suppression by dedupe identity.
- Replaced the order-service raw `analytics.events` publication for model-unavailable telemetry with the governed canonical event publisher. Actor pseudonymization is HMAC-backed when `EVENT_ACTOR_PSEUDONYM_KEY` is configured and safely falls back to `system` without leaking the raw id.
- Added one versioned analytics definition registry for GMV, completed order, cancellation, refund, active courier, active merchant, and SLA. It is served through the protected admin analytics endpoint and displayed in the Analytics page.
- Added event taxonomy, PII/retention, and analytics governance contracts plus staging CI coverage for datalake-worker tests/build.
