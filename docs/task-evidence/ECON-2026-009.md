- Added Admin endpoints for list/get/preview/simulate/approve/publish/rollback. Publish locks and updates the existing `system_configs` runtime source in the same transaction as the revision state; rollback restores the captured payload.
- Added tariff-backed example quotes and aggregate affected scope (market, zone, service, active order count). Examples are explicitly marked simulation-only; customer quote authority remains order-service.
