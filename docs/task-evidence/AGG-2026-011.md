# Evidence — AGG-2026-011

## Scope Implemented

- Moved the canonical carrier event contract into `domain.CarrierEvent`.
- Added `WebhookAdapter` and adapter registry contracts.
- Added provider-owned JNE and J&T webhook adapters for native payload parsing, raw-field preservation, canonical status normalization, and signature verification.
- Kept a generic raw-preserving adapter for an unregistered provider; the central handler logs that tracking is degraded/manual rather than treating it as a registered carrier.
- Reduced the central webhook handler to transport, adapter resolution, request authentication, event identity/hash, and forwarding to order-service; provider-specific payload switches were removed.
- Added a durable order-service target query and API-key-protected internal endpoint for active provider/AWB rows.
- Added a scheduled integration-gateway polling worker that invokes pull adapters, normalizes responses into the same raw-preserving carrier event contract, and publishes them to the existing order-service inbox.
- Registered webhook capability explicitly for JNE/J&T; webhook-capable providers are primary and are skipped by polling unless reconciliation is enabled. Registry descriptors expose `webhook`, `polling`, or `degraded_manual` tracking mode for customer UI.
