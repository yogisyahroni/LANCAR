## Scope Implemented

- Handoff proof/token paths retain hashed, order/actor/stage-bound, expiry-bound, attempt-limited semantics with replay/wrong-actor/max-attempt handling and audit events.
- GPS proof evaluation detects impossible movement (`impossible_location_jump`) and high-risk spoof signals; admin GPS risk alerts provide acknowledgement/resolution actions.
- Admin order exception queue now derives `repeated_post_dispatch_cancellation` when a customer has at least three cancelled orders after dispatch started in the last 30 days. The signal is read-only and routes operators to review/support rather than mutating order state.
- JNE/J&T/generic provider webhook adapters verify signatures at the provider boundary; tracking handlers reject missing/invalid signatures and carrier event inbox/state logic preserves replay/UNKNOWN/out-of-order behavior. Payout provider callbacks use timing-safe signature verification and replay-aware dispatch state.
- High-risk admin financial and operational mutations require authenticated admin roles plus TOTP; sensitive payout, ledger, invoice, claim, force-cancel, provider credential, and reconciliation routes also use idempotency where applicable. Force-cancel/refund actions persist actor, reason, previous/new state, and audit events.
