## Acceptance Criteria Source

## Scope Implemented

- Added a bounded orchestration module inside order-service because it owns food order state already; no second microservice or payment source of truth was created.
- A bundle stores one merchant slot and one independent child order per merchant. Attach requires the customer to own the child order, the child to be food, and its merchant to be a declared slot.
- Finalization requires every merchant slot to have a child order and computes aggregate gross total from persisted child orders; each child remains independently priced, paid, dispatched, and settled.
