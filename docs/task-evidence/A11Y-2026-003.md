- Survive WCAG text-spacing overrides without clipping, overlap or loss of content.

## Scope Implemented

- Added shared role-based typography variables to Customer Web and Admin CSS foundations.
- Set the body baseline to the shared body size and 1.5 line-height.
- Added browser checks that inject WCAG 1.4.12 letter-spacing, word-spacing, line-height and paragraph-spacing overrides at 320px across all registered Customer/Admin routes.
- Removed remaining emoji glyphs from order controls so iconography does not change with platform font fallback.
- Added full-content `title` affordances for truncated Customer dashboard addresses and used readable status labels instead of raw uppercase status codes in the order surfaces.
