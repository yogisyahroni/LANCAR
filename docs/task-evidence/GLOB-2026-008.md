## Scope Implemented

The existing feature flag control plane remains the shared platform configuration
boundary. A bounded experiment module in order-service now provides HMAC-derived
subject identity, deterministic basis-point bucketing, targeting evaluation,
PostgreSQL advisory-lock namespace exclusivity, assignment persistence, and an
authenticated explicit exposure endpoint. Treatment exposure is idempotent and
committed with a governed `experiment.exposure` event in the existing outbox.

Admin-service provides role/TOTP/idempotency-protected experiment CRUD and kill
switch APIs. The admin dashboard provides a real experiment list, creation of a
safe draft, activation, and kill-switch controls. Treatment payloads and target
attributes are allow-listed so financial truth remains with transactional
pricing/order services. Guardrail definitions cover crash/error, cancellation,
refund, ETA/SLA, and support contact signals.
