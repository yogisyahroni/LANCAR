## Scope Implemented

- Adjustment proposal persists the authoritative initial `quote_id`, `pricing_snapshot`, original total, structured material/labor items, computed delta, and proposed total.
- Customer consent UI shows the original price, delta, proposed total, itemized reason/work, and explicit `Setujui` / `Tolak` actions with a confirmation dialog.
- Approval updates order money state, adjustment state, decision idempotency metadata, and audit log inside one database transaction.
- Retry with the same decision key/fingerprint returns the persisted decision without applying money or audit a second time.
- Wrong-customer decision attempts fail closed before any money/state mutation.
