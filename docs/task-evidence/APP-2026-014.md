# Evidence — APP-2026-014

## Acceptance Criteria Source

Original checklist from `task-food-marketplace-parity-2026.md`:

- `[x]` Marketing/banner/help copy can be published per locale without app release.
- `[x]` Locale fallback order is explicit, e.g. `id-ID → id → default`.
- `[x]` Missing translation does not expose raw localization key.
- `[x]` Legal/financial/consent copy uses approved versioned content path, not casual marketing CMS override.
- `[x]` Remote copy has length constraints so layout remains stable.

These are the original APP-2026-014 requirements. Staging rollout and physical-device validation are recorded separately as release follow-up and were not converted into extra checklist requirements.

## Scope Implemented

- Added the append-only, revisioned `localized_content_pack_revisions` and audit tables beside the existing experience CMS. Published payloads are immutable; newer revisions supersede the active revision while preserving history.
- Added admin create/list/update-draft/publish routes with role, TOTP and idempotency protection, plus a dashboard page for locale-specific marketing/banner/help copy and revision history.
- Added public content-pack resolution and server-side resolution of optional `localized_copy` references inside existing experience manifest sections. A published copy revision changes the public manifest checksum/signature without an app binary release.
- Implemented the explicit fallback chain: requested full locale, requested language, market default full locale, market default language, `id-ID`, then `id`.
- Missing references are omitted from the response; raw localization keys are never emitted. Existing literal presentation values remain the safe fallback when present.
- Protected key segments (`legal`, `financial`, `consent`, `payment`, `tax`, `price`, `transaction`, and related terms) are rejected from the marketing CMS. Existing approved versioned market legal-document APIs remain the compliance path.
- Enforced bounded remote copy sizes: marketing 500 characters, banner 320 characters, help 700 characters, with unsafe markup/executable URL rejection and manifest field limits retained.
