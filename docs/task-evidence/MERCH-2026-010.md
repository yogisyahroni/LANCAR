The gate creates and cleans generated catalog/order/staff fixtures, drives merchant acceptance and ready transitions, verifies branch/catalog ownership, checks finance staff read-only scope versus owner-only withdrawal, and proves Search outbox events plus server-authoritative checkout pricing.

Added an admin-service probe that runs the merchant and order integration gates plus the existing finance, Ads, enforcement, quality, operating-state and discovery boundary suites against the same local database, followed by canonical merchant eligibility assertions. Added a static contract suite covering onboarding, branch/RBAC, catalog/Search, operating eligibility, finance, Ads and enforcement/appeal ownership.

Adjusted the existing finance integration assertion to compare generated statement deltas against the live fixture baseline, preserving the append-only production invariant when the shared database already contains historical entries.
