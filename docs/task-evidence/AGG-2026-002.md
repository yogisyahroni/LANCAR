## Scope Implemented

- Routed aggregator GPS reverse geocoding through the existing server endpoint `GET /maps/reverse-geocode`; the browser no longer calls Nominatim directly.

- Extended the admin maps provider normalization for OSM and TomTom search/reverse responses so provider output exposes structured address parts without replacing the display label.
- Added server-side enrichment from `provider_area_mappings`, including exact provider area code and mapping id, versioned mapping metadata, and postal/district-safe matching. Browser input cannot supply or override provider codes.
- Cached the server mapping snapshot in Redis and cached only the normalized geocode result; existing provider observation records remain on every cache/provider path.
- Preserved the existing backend-owned provider configuration, fallback policy, and observation path. The listed integration-gateway/order-service maps files were inspected and were not changed because public geocoding is already routed through admin-service in this repository.
