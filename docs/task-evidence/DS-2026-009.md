# Evidence — DS-2026-009

## Acceptance Criteria Source

- `[x]` Android functional icons use one approved family/style; decorative 3D/service illustrations are not used as replacements for critical action icons.
- `[x]` Five primary services have distinct canonical icon + label mapping across Home, history, detail and notifications.
- `[x]` Marketing campaign art can change remotely but must respect safe aspect ratios/text zones/accessibility fallback.
- `[x]` Define image aspect-ratio presets for hero banner, merchant card, sponsored card, category tile, campaign intro and empty state.
- `[x]` Define low-bandwidth/static fallback for animated creative.
- `[x]` External merchant creative cannot upload arbitrary UI-like fake buttons, system dialogs or misleading notification treatments.

## Scope Implemented

- Added `TembusMediaGovernance` with the six named TEMBUS media presets, aspect-ratio tolerance, safe-text-zone vocabulary, byte budgets, and static fallback compatibility rules.
- Extended `ExperienceManifestValidator` to reject invalid safe zones, animated/video assets without compatible static fallback, invalid fallback chains, and asset/component ratio mismatches. Existing sanitized property allowlists continue to prevent executable HTML/UI chrome; app-owned CTA semantics remain renderer-owned.
- Added `TembusServiceIconSpec` as the canonical functional icon + label registry. Home, order history, order detail, and notification activity rows now resolve service identity through the same registry; unknown codes use a neutral `Info` mapping.
- Documented the icon family, media presets, creative safety, low-bandwidth behavior, and accessibility fallback in `docs/design/tembus-icon-media-governance-2026.md`.
