## Scope Implemented

Loyalty order events are accepted only on the internal authenticated boundary, mapped to append-only `EARN/REDEEM/EXPIRE/REVERSE` entries, update a points projection, and carry optional currency-equivalent liability. The ledger is separate from payment withdrawable balances and uses a unique order/event idempotency key.
