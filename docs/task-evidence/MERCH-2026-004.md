## Scope Implemented

- Added canonical merchant operating states and per-merchant IANA timezone to
  the existing merchant aggregate, preserving `is_open`, pause, and busy
  compatibility fields.
- Added migration `20260908000014_merchant_operating_state.sql` with safe
  backfill, constraints, state versioning, audit history, and a durable
  `merchant.operating_state.changed` outbox trigger routed to Search and Ads
  eligibility consumers.
- Updated merchant self-service transitions and the timezone-aware operating
  hours worker. Active pause, busy, temporary closure, and indefinite admin
  override are protected from schedule projection.
- Added authenticated admin/support override endpoint with role allow-list,
  TOTP step-up, required reason, future temporary-closure expiry, atomic audit,
  and state update.
- Updated order quote/create, scheduled activation, group/bundle creation,
  merchant detail, favorites, and discovery eligibility to consume canonical
  operating state. Busy remains orderable and retains its prep-time ETA delta;
  paused/closed/holiday/temp-closed states reject new order flows.
