## Scope Implemented

- Added a provider-neutral `Location` contract with display address, normalized address components, coordinate, accuracy/source, provider metadata, timezone, market, and synchronized address/coordinate versions.
- Added transactional coordinate validation for finite ranges and explicit rejection of `0,0`.
- Added content-derived `Revision()` and `SameRevision()` so address or coordinate changes cannot reuse a quote/route location snapshot.
- Wired canonical pickup/dropoff locations into the routing request while preserving the legacy coordinate request. When both are provided, the values must match.
- Documented provider metadata and snapshot/revision rules in the geo contract.
