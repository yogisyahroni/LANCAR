# Evidence — FOOD-2026-026

## Scope Implemented

- Removed all `contentDescription = null` occurrences from customer and merchant Compose UI; decorative icons use `""`, actionable icons retain localized labels.
- Replaced explicit sub-48dp interactive icon sizing with `sizeIn(minWidth = 48.dp, minHeight = 48.dp)` across audited controls, including food cart quantity, merchant favorite, rating, notification, chat, dashboard, tracking, and menu actions.
- Added `Role.Button` semantics to food merchant/menu navigation cards.
- The design system defines a 48dp minimum interactive target and uses `sp`/Material typography for scalable text.
- The shared guard validates source semantics, interactive sizing, scalable text units, and the design-system WCAG contrast pairs for both light and dark palettes.
- Food discovery, cart, checkout, merchant cockpit, and receipt surfaces contain no custom animated transition; state remains usable without motion-dependent meaning.
- Compose layouts use width-filling/lazy/scrollable primitives and do not depend on a fixed phone width, supporting larger windows at the code level.
