## Scope Implemented

- Catalog and stock sync are backed by merchant menu CRUD, availability, inventory quantity/daily-limit updates, and atomic repository guards.
- Reconciliation surfaces are backed by sales reports, CSV export, settlements, and withdrawal history; the order service remains authoritative for order/payment state.
- Connector health is exposed through the merchant service health endpoint and explicit bounded failure responses; no printer failure is treated as an order failure.
- `PrintQueuePolicy` adds a three-attempt queue state machine (`QUEUED -> PRINTING -> SUCCEEDED/FAILED`) with capped exponential backoff.
- `EscPos.printWithRetry` isolates Bluetooth connect/write failures, closes the socket on every attempt, and reports the final error through the merchant snackbar without changing server order state.
