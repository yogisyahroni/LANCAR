## Scope Implemented

- Extended the existing App Experience CMS editor with campaign name/reference, target surface, placement, localized copy keys, badge, accessibility label, CTA/deep-link controls, asset/fallback references, audience targeting, schedule/timezone, frequency limits and percentage rollout.
- Added AssetPicker-backed asset selection and backend validation for referenced asset existence, content type, byte size and dimensions before draft save or publish.
- Kept deep links and first-party external URLs allowlisted; invalid destinations fail the manifest validation/publish path.
- Kept promotional presentation separate from economics: the editor labels promo content as presentation-only and the existing Promo/Pricing backend remains authoritative for discount and eligibility.
- Added stable server-side percentage rollout bucketing per authenticated user, an audience preview user ID, campaign status presentation, duplicate-as-draft, pause/resume, retire and existing rollback controls.
- Added the retire API lifecycle transition to `superseded`, preserving revision history and audit evidence while removing retired published content from public selection.
- Preserved campaign ID and manifest revision in native banner/promo analytics and added alt-label content descriptions for accessible rendering.
