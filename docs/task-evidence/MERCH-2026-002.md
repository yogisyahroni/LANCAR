## Scope Implemented

- Added canonical merchant branches with a repair-safe migration, unique merchant/code identity, active-state handling, and seeded `MAIN` branches for existing merchants.
- Added canonical staff roles `manager`, `kitchen`, `cashier`, `marketing`, and `finance`, while accepting legacy `kasir` as a compatibility alias. Staff can be assigned to one or more branches.
- Added opaque device sessions bound to user, merchant, branch, and device. Authorization is server-side, checks current role permissions and active membership on every request, and records last-seen/revocation state.
- Added database triggers that revoke staff sessions when staff is revoked and branch sessions when a branch is deactivated.
- Added owner-managed branch/staff/session endpoints and propagated session permission checks through merchant menu, promo, order, report, and withdrawal paths.
- Added step-up authentication plus separate approval records with idempotency for bank-account, payout, and merchant-configuration changes. Approval requires an authorized approver distinct from the requester.
- Added the API/domain contract at `docs/contracts/merchant-branch-staff-rbac-2026.md` and updated the dashboard role vocabulary.
