## Scope Implemented

- Added the append-only `merchant_statement_entries` projection with separate
  sale, commission, tax, promo subsidy, refund, fee, Ads spend, adjustment,
  and payout entry types. Settlement, processed refund, and completed
  withdrawal triggers materialize source facts idempotently; Ads and finance
  corrections use the same validated append boundary.
- Added merchant-scoped reads through the existing report repository and a
  protected `/api/v1/merchant/finance-statement` endpoint. It returns separate
  category totals, signed balance effects, and open/under-review exceptions
  from the canonical global `finance_reconciliation_exceptions` queue.
- Added bank-account lifecycle fields, versioned last-four audit events, and a
  configurable 24-hour cooldown. The authenticated route requires gateway
  identity, owner scope, TOTP step-up, and an approved high-risk security
  approval; payout disbursement rejects an active cooldown or market mismatch.
- Added immutable financial-fact guards. Historical statement rows reject
  update/delete and corrections are represented by new `adjustment` entries.
- Added explicit market, ISO currency, minor-unit, and currency-aware amount
  fields to merchant settlements and withdrawals. IDR legacy writers remain
  compatible; non-IDR settlement/withdrawal rows require minor units, unknown
  market configuration fails closed, and the current IDR-only payout gateway
  fails closed for non-IDR payout rather than sending a zero-IDR transfer.
