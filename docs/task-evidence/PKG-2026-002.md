## Scope Implemented

- Added a shared package-facts shape across Android request/response models,
  Web form schema/submit payload, and the admin/order pricing path.
- Captured quantity, category, item description, item value, fragile/prohibited
  flags, size tier, receiver, and delivery-code policy as real user input.
- Quantity now participates in server-authoritative actual, volumetric, and
  chargeable weight totals. Explicitly prohibited packages are rejected before
  quote/order processing.
- Android and Web now invalidate/recalculate the quote when package facts or
  receiver facts change, and both render the server-returned package facts and
  authoritative weight breakdown.
- Order persistence receives the same package facts through `package_details`
  and normalized package records; no placeholder facts are introduced.
