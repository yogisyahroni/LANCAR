## Root Cause

`selectedDestination` (`rememberSaveable`, default `"home"`) bertahan saat user
pergi ke History/Profil/Bisnis (route terpisah) lalu kembali via Back —
pill Riwayat tetap menyala di atas konten Beranda (dibuktikan crop screenshot
`nav_crop.png`: pill hijau di Riwayat).

## Implementation

`DashboardScreen.kt`: `LaunchedEffect(Unit) { selectedDestination = "home" }`
dengan komentar UIUX-2026-002. Dashboard yang tampil = home; semua item nav
navigasi ke route terpisah, jadi reset-on-compose selalu benar.
