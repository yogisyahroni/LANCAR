# Evidence — TOW-2026-005

## Scope Implemented

- The courier proof upload endpoint checks the assigned `order_legs` status before accepting `vehicle_photo_before`. Once the leg is `in_transit` or downstream (`arrived_dropoff`, `unloading`, `completed`, `delivered`, `cancelled`, or `failed`), the endpoint returns `ERR_PROOF_IMMUTABLE` and does not save the upload.
- The proof endpoint already binds uploads to the authenticated courier's assigned order leg. The towing report repository also keeps completion creation idempotent per order under a transaction lock.
- Towing completion now writes a structured, non-PII audit event to `audit_logs` containing proof context and damage decision fields (`severity`, `safe_to_transport`, and area count when present). The raw image is not copied into the audit payload.
