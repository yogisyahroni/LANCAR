## Scope Implemented

- Added a server-side fairness evaluator. It compares baseline/candidate courier earning p10, merchant top-share/HHI, no-supply rate, customer price p95, cancellation/acceptance deltas, and new/small merchant discovery. A positive revenue uplift is retained as informational data and never overrides a failed guardrail; failed evaluation returns HTTP 409 from the protected Admin endpoint.
- Added aggregate Admin monitoring at `/admin/analytics/marketplace-fairness`, scoped by market/zone/service and bounded to a 1–168 hour window. It reads authoritative order, order-leg, courier earning ledger, zone, and food discovery facts, returns distribution/concentration/outcome metrics, and emits per-dimension outlier flags without exposing identifiers.
- Kept organic merchant ranking independent from commercial commission. `RankFoodMerchants` uses distance, rating confidence, rating count, and separately labelled sponsorship; commission contracts are not part of the discovery input or score.
- Added `marketplace_pricing_kill_switch` to `system_configs`. When enabled, dynamic and peak pricing decisions use multiplier `1.0`, preserve policy/version context, and cause stale dynamic-pricing quotes to follow the existing server-side requote path.
