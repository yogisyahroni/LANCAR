## Scope Implemented

- Added the canonical courier enforcement action model for `restriction` and `suspension` across `account`, `market` and `capability` scopes, with reason category/detail, actionable courier message, disclosure policy, effective window and safe active-job policy.
- Added safe-job handling for allow-active-job-completion, unpicked-job reassignment and immediate safety stop. Pending safe completion is finalized by the database trigger when active order legs change, while matching and capability eligibility are blocked by the server-side enforcement gate.
- Added mobile enforcement visibility with actionable reason categories. Security-restricted investigations expose the category and safe guidance without leaking sensitive detail.
- Added persisted appeals, immutable action events, audited admin review timeline, duplicate-open-appeal protection and approved/rejected review transitions.
- Added snapshot-based reinstatement that restores only capabilities and account status that were approved before the enforcement, and only when no overlapping active enforcement still applies.
- Routed the legacy direct admin suspension endpoint into the audited enforcement workflow so it cannot bypass reason, safe-job policy, appeal and audit requirements.
