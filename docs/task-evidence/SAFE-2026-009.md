## Scope Implemented

Resolved safety incidents can emit one append-only `QUALITY_RECALCULATE` reputation signal only after a resolved audit event, with server-derived subject/order/counterparty and a versioned safety rule. The signal is explicitly non-enforcement. Support cases resolve safety references to the order while ordinary agents receive a redacted reference; sensitive incident data remains safety-role scoped.
