# Evidence — TOW-2026-003

## Scope Implemented

- Server pricing continues to calculate the route from pickup to the normalized towing destination and returns the route snapshot/operator metadata.
- The price breakdown exposes service fee, travel/distance, platform, insurance, dynamic/material, and explicit toll fields. Toll is added to the server total only when a configured service toll value exists; otherwise the source is explicitly `unavailable` and the customer sees that it is not included.
- Order creation recalculates the price server-side and does not use the client total as authoritative.
- A stale quote, changed route snapshot, or material increase returns `REQUOTE_REQUIRED` with the trusted latest breakdown. The order is not created until `quote_consent=true` is submitted.
- The Android customer flow renders the latest trusted breakdown, shows the exact increase, requires a checkbox consent, retries with the consent token, and sends the quote snapshot hash/total.
- Consent and both quote totals/hashes are recorded in `order_events.metadata` for auditability.
