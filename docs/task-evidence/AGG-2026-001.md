## Scope Implemented

- Added runtime availability to the backend provider descriptor and diagnostics. JNE/J&T report missing credentials and open circuit state from the same adapter used for provider calls.
- Made integration-gateway `GET providers` and provider quote/create paths use the runtime availability state; unavailable providers cannot be quoted or created.
- Removed the global `awb_origin_code`/`awb_destination_code` substitution from aggregator quote validation. Provider area codes are now required from the validated mapping selection.
- Kept provider area lookup server-backed through `provider_area_mappings` and removed the admin controller's hardcoded provider whitelist so new registry-backed providers are not rejected by stale UI/controller truth.
- Disabled unavailable providers in both aggregator UI flows and removed the bulk-upload fallback from a missing provider to `tembus_instant`.
