# Evidence — AGG-2026-003

## Scope Implemented

- Added a canonical authenticated `/api/v1/logistics/tariff` path through
  admin-service to order-service and the integration gateway.
- Accepted normalized origin/destination codes, actual weight, dimensions,
  item value/category, and insurance/COD flags. Chargeable weight is the
  greater of actual and volumetric weight using the documented 6000 divisor.
- Persisted one immutable `aggregator_rate_quotes` row per native service with
  provider/service identity, gross/net/customer tariff, normalized category,
  ETA/source, rule version, and expiry.
- Added `aggregator_quote_id` to payment links. A supplied quote is rejected
  when missing, expired, or mismatched; checkout reuses its stored tariff
  rather than recalculating it.
- Removed the J&T `1-3 hari` fallback. ETA is empty unless returned by the
  provider, and JNE marks provider-sourced ETA explicitly.
- Propagated quote IDs, package dimensions, value/category, insurance/COD and
  ETA provenance into the merchant aggregator wizard and tariff hook.
