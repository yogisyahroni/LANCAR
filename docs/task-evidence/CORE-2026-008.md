## Scope Implemented

### Backend (`domain`, `middleware`, `service`, `handler`)
1. **Standardized error codes (item 1):** `domain.TypedError` struct (`Code`, `UserMessage`, `Recoverable`, `Err`) + `ErrCode` constants for all 14 blueprint codes (`REQUOTE_REQUIRED`, `OUT_OF_SERVICE_AREA`, ... `CARRIER_EVENT_UNKNOWN`) plus transport codes (`ERR_VALIDATION`, `ERR_NOT_FOUND`, `ERR_INTERNAL`, etc.). `HTTPStatus()` maps code → HTTP status. 14 sentinel `ErrTyped*` vars pre-configured with user message + recoverable flag.
2. **Error carries correlation id (item 2):** `ErrorResponse` gains `Recoverable` field; `WriteAppError(w, err)` renders `*TypedError` → canonical JSON with `code`, `UserMessage`, `CorrelationID` (extracted via `GetCorrelationIDFromError`) + `Recoverable`. `validator.go` now emits standardized codes (`domain.CodeInvalidBody`, `domain.CodeInvalidJSON`, `domain.CodeValidation`) instead of literal strings.
3. **publishOrderEvent** stamps monotonic `Version` (via `eventRepo.NextEventVersion`) + `CorrelationID` server-side before SaveEvent → Publish, making event ordering authoritative.
4. **Migration** `20260902000006_add_order_event_version.sql`: adds `version bigint`, `correlation_id uuid`, `idx_order_events_order_version UNIQUE (order_id, version) WHERE version > 0`, backfills ascending versions.
5. **WS handler dedupe**: `broadcastToRoomFromEvent` parses `version` + `order_id`; `lastVersion` map (mutex-safe, keyed `userID:order_id`); drop if `Version <= lastSeen`, bump if newer.

### Client-side (client renders next action, not raw error — item 3)
- **Frontend `api.ts`**: `normalizeApiError` reads `error.response.data.code`, `correlation_id`, `recoverable`, `message` → attaches `apiCode`, `correlationId`, `recoverable`, `userMessage` to axios error before reject. UI reads `error.userMessage` / `error.apiCode`.
- **Frontend `useWebSocket.ts`**: client-side dedupe of `order_updates` events via `lastEventVersion` map per `order_id`; drops older/duplicate on replay. Emits `sync_request` on reconnect so server returns authoritative `sync_resume` version.
- **Courier `SocketManager.kt`**: emits `sync_request` on `EVENT_CONNECT`; handles `sync_resume` event (stores `last_version`); client-side dedupe on `order_tracking_updated` by `version <= lastSeen`.
- **Courier `ErrorReference.kt`**: `TembusError` sealed class mapping all 14 codes + transport codes → `{message, nextAction, correlationId}` with `Action` enum (`RETRY`, `PICK_METHOD`, `REQUOTE`, `PAY_FIRST`, `PROOF`, `AUTH_RELOGIN`, `CONTACT_SUPPORT`, `NONE`). `retrofit2.Response<T>.toTembusError()` parses backend `errorBody` → typed error.
