meng-encode nama via `URLEncoder` (spasi jadi `+`), tetapi `RootNavGraph`
membaca `courierName` tanpa decode (rute Chat di file yang sama SUDAH decode —
pola yang benar sudah ada di line 643).

## Implementation

`getOrDefault(raw)` — nama sah bertanda `+` literal tidak dirusak karena
decode hanya mengubah sekuens `%XX`/`+` hasil encode (komen UIUX-2026-003).
