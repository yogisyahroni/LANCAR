## Scope Implemented

- Added a server-owned food-pricing experiment configuration in `system_configs`, with bounded traffic, treatment multiplier, rule versions, salt, active window, and guardrail thresholds.
- Added byte-compatible deterministic assignment for customers in order-service and couriers in Admin dispatch using SHA-256 of experiment, subject type, subject ID, and salt. Assignment, variant, rule version, and quote-window expiry are persisted in quote/order metadata.
- Applied the treatment multiplier only after existing dynamic-pricing policy evaluation and clamped it to the existing effective ceiling. The order path reuses the immutable quote multiplier during the quote window instead of silently re-pricing an active contract.
- Added server-side guardrail evaluation from order snapshots, courier earnings ledger, and dispute data for cancellation, ETA, support contact, courier earnings, and platform margin. Harm guardrails fail closed; revenue is not allowed to override a failed guardrail.
- Added Admin configure/evaluate/kill endpoints with role, TOTP, idempotency, audit logging, server-side metrics, and salt redaction. The kill operation changes only the future assignment source and explicitly leaves active quote/order snapshots untouched.
- Added a reversible migration, experiment snapshot index, and fresh-primary config reads for safety-critical kill-switch/experiment decisions.
