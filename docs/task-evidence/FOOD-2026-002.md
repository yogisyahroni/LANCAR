## Scope Implemented

- `POST /api/v1/orders/food/quote` validates the selected approved/open merchant, menu ownership and availability, variant ownership/rules, destination/radius, configured delivery fee, configured tax, voucher, and schedule.
- Quote response contains per-item server prices, subtotal, delivery fee, platform fee, tax, discount, total, distance, ETA, ETA source, pricing rule version, fingerprint, and expiry.
- Quote is persisted using the existing Redis quote envelope with the exact Food input payload needed for create validation.
- Food create requires a live unexpired Food quote, matches the fingerprint, recalculates the server total, rejects changed pricing with `REQUOTE_REQUIRED`, and persists the quote response as `orders.pricing_snapshot`.
- Checkout explicitly requests/re-requests the quote after address, voucher, schedule, or destination changes and cannot submit without one.
