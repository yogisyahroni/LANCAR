## Scope Implemented

GLOB-2026-009 now has an operational service/dependency catalog, measurable
SLI/SLO and alert thresholds, a capacity model for all requested critical
flows, an error-budget release policy, incident-command/postmortem workflow,
and provider/database outage runbooks.

The order-service HTTP boundary now has a configurable per-instance,
fail-fast transactional load shedder (`TRANSACTION_MAX_INFLIGHT`, default 64).
It protects mutating authoritative paths while leaving quote/read-like paths
available and returns a typed retryable `ERR_TRANSACTION_LOAD_SHED`. Shared,
order-service and integration-gateway circuit breakers now serialize half-open
recovery probes so a provider recovery cannot create a probe stampede.

Existing gateway bulkheads, Redis-backed limits, provider retry budgets,
RabbitMQ persistent/DLQ behavior and idempotency remain the underlying
resilience primitives. Prometheus now records and alerts critical-service
availability/latency by `service_name`. A seven-scenario deterministic
fault-injection matrix covers Redis, database replica, queue, maps, payment,
carrier and notification failures.
