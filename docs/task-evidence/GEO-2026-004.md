## Scope Implemented

- Route snapshots now carry explicit `source` (`live_provider`, `cache`, `fallback`, or `disabled`) and `provider_version`, alongside generated time, provider, traffic flag, confidence, summary, and geometry.
- Cached/legacy route snapshots are normalized with honest provenance; stale cache is marked as fallback and confidence is reduced rather than treated as fresh provider truth.
- Added immutable-raw GPS derivation: route-point map matching and bounded exponential smoothing produce a separate display point while preserving raw telemetry exactly.
- Added explicit GPS quality states for fresh, stale, low accuracy, and invalid samples, including display/navigation eligibility and reasons; tracking responses expose derived location/quality separately.
- Existing route cache/circuit controls remain provider/profile/service scoped with bounded TTL and stale-cache fallback, preventing unbounded recalculation/provider calls.
