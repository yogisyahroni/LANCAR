# Failure drill record template — PART AG

Use one record per injected failure:

- Timestamp and environment:
- Commit/image digest:
- Dependency/failure injected:
- Expected safe behavior:
- Observed behavior and telemetry:
- Idempotency/recovery result:
- Gap or customer impact:
- Owner and remediation due date:
- Rerun timestamp/result:

An unfilled template is not drill evidence. Vendor sandbox and production-safe
rehearsals must be explicitly labeled; local unit tests are not substituted for
them.
